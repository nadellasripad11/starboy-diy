starboy

a chrome star you clip to your pants, with a tiny round screen for an eye. shake it and it gets dizzy, take it somewhere cold and it shivers, yell near it and it gets nervous. leave it alone and it falls asleep.

1.28" round screen 3 sensors 400 eye combos ~4h per charge
make it react

what it does

it reacts to you

the star has a motion sensor, a temperature sensor and a microphone inside. tap a reaction to see exactly what the screen does. these animations run the same code as the real firmware.

rare effects · one might play every ~90 seconds

idle · looking around

the eyes

100 colorways × 4 shapes

the first time a star turns on, it rolls one colorway and one eye shape and keeps them forever. some colorways are common, some show up 0.4% of the time. the rarest ones give each eye a different pupil.

what's inside

a whole computer in a keychain

everything is hand-wired, no custom circuit board, so it all folds into a shell just 20.5mm thick. the shell is 3d printed in petg, sanded, primed and sprayed chrome.

seeed xiao esp32c3the brain. thumbnail-sized, charges the battery over usb-c
gc9a01 round screen1.28", 240×240 pixels. this is the eye
mpu6050feels shaking and tilting
ds18b20pokes out of a tiny vent to read the air temperature
max4466 michears loud sounds
320mah lipoabout 4 hours per charge, dims itself when sleepy

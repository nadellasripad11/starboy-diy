tuning console

every star listens over usb. plug him in, open a serial monitor and you can make him shiver, play any effect, check his wiring or change how sensitive he is, all without reflashing.

connecting

1. plug in usb-cthe same port he charges from
2. open a serial monitorarduino ide, 115200 baud, newline line endings
3. type helphe lists every command, mood and effect

looking around

status

his current mood and how long he's been in it, his eyes and seed, live sensor readings and every tuning value

hw

which parts he can find: screen, motion sensor, temperature sensor and mic. anything missing comes with the wire to check

debug on

prints shake, temperature and sound once a second. debug off stops it

making him react

mood <name>

jump straight to a mood

fx <name>

play a rare effect right now

fake temp 2

pretend the air is 2°c. moods that depend on the cold end right away without this

fake sound 2000

pretend the room is loud. fake off goes back to the real sensors

demo

a ~77 second tour for filming: loud room, cold, shaken, four rare effects, falling asleep and waking up. demo stop ends it early

tuning him

every star's sensors are a little different. changes apply live, and save keeps them after a restart. defaults puts everything back.

set shake 16

how hard a shake has to be to make him dizzy, in m/s² above gravity

set cold 10

the temperature in °c where he starts feeling chilly. he warms back up 1°c above it

set loud 600

how loud it has to get before he's startled. depends on the mic's gain knob

set tempoffset 0

corrects the temperature reading. the sensor sits near the warm board, so compare status with a real thermometer once

set doze 25

seconds alone before he starts dozing

set sleep 75

seconds alone before he's fully asleep

set rare 90

seconds between chances of a rare effect

a good first tuning session

> hw
check every part shows up before anything else
> debug on
leave him still in a quiet room for a minute and note the sound number
> set loud 900
a few hundred above the quiet level, so talking doesn't startle him
> set tempoffset -2
if status reads 2°c warmer than a real thermometer
> save
> demo
start recording

these defaults are the firmware's starting values; the right numbers for your star come from the real parts.
